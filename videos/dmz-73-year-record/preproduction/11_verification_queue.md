# 11. 원문 확인 큐 — 네트워크 허용 시 즉시 실행

> 2026-09-29 세션에서 아래 호스트가 전부 이그레스 정책에 막혔다(CONNECT 403). 확인 작업이 **전부 대기 상태**다.
> 망이 열리면 이 문서를 위에서부터 그대로 실행한다. **무엇을 뽑아야 하는지가 ID마다 다르므로** 즉흥으로 하지 말 것.

## 1. 국가기록원 — 레코드 단위 확인

`theme.archives.go.kr`(주제별 전시)의 표시와 다를 수 있다는 점이 미해결 쟁점이다.

| ID | 대상 | 뽑을 것 |
|---|---|---|
| R02 | 1953 정전협정 체결, 관리번호 **`CET0048202`** | 레코드 단위 공공누리 유형 / 제공 해상도 / 사본신청 절차 |
| R01 | 군사분계선 푯말 (**기증기록** `archDonatedId=002093`) | **기증자 저작권 잔존 여부** — 일반 소장본과 절차가 다르다 |
| R06 | 1976 판문점 도끼 사건 | **관리번호부터 추출** (현 URL은 해설 페이지) |

## 2. 통일부 — 출처 URL 재작성

R03·R04는 현재 `common/download.do?...` 파일 엔드포인트라 이용조건이 표시되지 않고 문서명·발행일도 남지 않는다.

| ID | 뽑을 것 |
|---|---|
| R03 | **게시물 상세 URL** + 문서 제목 + 발행일 + 발행기관 + 공공누리 유형 |
| R04 | 동일. 단 GP 세부(11/10/1)는 여기 말고 **국방부 1차 발표문**으로 간다(큐 7번) |
| R11 | 지식사전 항목 원문 확인. **8·25 공동보도문 원문**은 별도 확보 — 사전 항목으로 따옴표 인용 불가 |

## 3. 🔴 1970년대 땅굴 — 1차 출처 탐색 (대본 복원 조건)

`05_script_v1.md` 2장의 보류 항목 ①을 되살리려면 이게 먼저다.

찾을 것: **각 땅굴의 발견 일자와 공식 명칭이 명시된 1차 자료.**

- 국방부·통일부 발표문 또는 백서류
- 국가기록원 개별 기록물(관리번호가 있는 것)
- 후보 검색어: `제1땅굴`, `제2땅굴`, `제3땅굴`, `남침땅굴 발견`, `땅굴 탐지`

> 확보되면 `04_factcheck.md` 해당 행을 `unsupported` → `확인`으로 올리고, `05_script_v1.md` 2장 ⏸️ 블록의 원문을 복원한 뒤, `02_timeline.md` 연도카드를 3개로 되돌린다. **세 파일을 함께 고쳐야 한다.**

건수는 `09_download_sites.md`에 실측돼 있다. **남은 건 건별 공공누리 유형이다.**

| 자산 | 대상 | 판정 기준 |
|---|---|---|
| A07 | 두루미 새소리 오디오 **6건** | 제0·1유형이면 사용. **제2(상업금지)·제4유형이면 탈락** |
| A08 | `파주_제3땅굴` 이미지 | 동일. 3장 소재 후보 |
| A09 | 흑두루미 이미지 41건 | 유형 + **촬영지·종 확인**. 순천만 촬영분이면 “DMZ”로 쓸 수 없다 |
