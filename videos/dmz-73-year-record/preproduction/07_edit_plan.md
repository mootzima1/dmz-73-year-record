## 그래픽 사양

- 지도는 직접 제작한 단순 벡터 기반으로 사용한다. 타인의 지도 타일·위성사진은 별도 이용 조건을 확인한다.
- 사건 카드는 `연도 / 한 문장 / 출처표식` 3요소만 유지한다.
- 본편에는 출처표식 `NATIONAL ARCHIVES`, `MOU`, `MND BRIEFING`을 작게 넣고, 전체 URL은 설명란·엔드카드의 자료 목록으로 분리한다.
- 내레이션 자막은 2줄 이내, 중요한 연도와 단어는 크기 대비로 강조한다.

## 기술 구현 — 이 프로젝트에서 밟으면 안 되는 함정

> 프로젝트 CLAUDE.md의 축적된 실패 이력 중 **이 영상에 직접 걸리는 것**만 추렸다.
> 공통 성질: **전부 에러 없이 조용히 틀린 결과를 낸다.** 프레임 수 검산도 통과한다.

### ⛔ 역사 사진에 `zoompan` / 표현식 `crop` 켄번즈 금지

이 영상은 기록 사진이 주력이다. 두 필터 모두 크롭창 x/y를 매 프레임 **정수 픽셀로 반올림**해서, 느린 줌에서 프레임당 이동이 0.1~0.3px이면 몇 프레임마다 1px씩 계단으로 튄다. 실사 영상은 원래 움직여 안 보이고 **정지 사진에서만** 드러난다.

→ 서브픽셀 켄번즈를 쓴다(`source video/0916/nuri/kenburns.py`의 `render()`): 최대 줌 기준 `INTER_AREA` 1회 축소 → 매 프레임 실수 배율·실수 오프셋 아핀 `warpAffine(INTER_CUBIC)` → raw 파이프.
실측: zoompan 평균 0.58px/최대 1.06px → 서브픽셀 0.014px/최대 0.15px(**약 40배**).

### ⛔ `-frames:v N`은 N프레임을 보장하지 않는다
in-point 이후 소스가 모자라면 **조용히 적게** 나온다(실측 180 요청에 168). 렌더 전 `클립길이 − in_point ≥ 필요시간` 검사, 렌더 후 실제 프레임 수 확인.

### ⛔ 한글 경로 — `cv2` 쓰기/읽기 모두 실패
경로에 `바탕 화면`·`vs코드`가 들어가 **상시 위험**. `imwrite`는 예외 없이 `False`만 반환하고, 절대경로면 `imread`도 조용히 `None`.
→ `cv2.imencode` + 파이썬 파일객체 / `cv2.imdecode(np.fromfile(p, np.uint8), ...)`.

### ⛔ `subprocess(text=True)`는 한글 경로에서 cp949로 죽는다
ffmpeg가 stderr에 경로를 찍는 순간 `UnicodeDecodeError`. `capture_output`이면 `r.stderr`가 `None`이 되어 엉뚱한 `AttributeError`로 나타난다. → `encoding='utf-8', errors='replace'`.

### ⛔ 색범위 태그 — `-colorspace bt709`를 같이 줄 것
사진(`yuvj420p/pc`)과 영상(`yuv420p/tv`)이 갈리는데 `concat -c copy`면 태그가 하나만 남는다. PNG 입력은 `-color_range tv`만으론 VUI가 생략돼 `unknown`이 되므로 `-colorspace bt709` 필수. 납품 규격의 Rec.709는 여기서 지켜진다.

### ⛔ `loudnorm` 뒤 `aresample=48000`
loudnorm은 출력을 192kHz로 강제한다. 안 붙이면 aac가 **96kHz**로 인코딩되는데 경고가 없다. 납품 규격 `48kHz`가 조용히 깨진다.
측정 패스는 `-v info`로 돌릴 것 — `-v error`로 누르면 1패스 측정이 사라지고 조용히 1패스로 폴백한다.

### ⛔ `-map 0:v:0`을 공용 인코딩 상수에 넣지 말 것
EXIF 썸네일 딸린 사진 대응으로 넣으면, `filter_complex` 합성에서 **자막·출처표식·브랜드마크가 전부 사라진다.** 에러도 없고 프레임 수 검산도 통과한다. `-map`은 단일 입력 렌더에만.

### ⛔ 긴 렌더 전 절전 차단
이 PC는 유휴 5분이면 절전. 백그라운드 렌더는 입력이 없어 바로 걸린다(과거 2시간 43분 손실). `keepawake.py`를 별도 프로세스로. `ES_DISPLAY_REQUIRED`는 걸지 않는다.

### ⛔ 같은 작업폴더로 렌더 2개 동시 금지
서로 덮어써서 **구·신 혼합본이 정상 종료**된다. 길이도 프레임 수도 맞아 자동 검증으로 안 잡힌다. `taskkill`은 이 환경에서 조용히 실패하므로 `Get-CimInstance Win32_Process`로 **세어서 확인**하고 작업폴더를 비운 뒤 재시작.

## 오디오 — BGM 조달 규칙 (프로젝트 전역)

- **BGM은 유튜브 스튜디오 오디오 보관함(YTAL) 음원만 사용.** Pixabay 등 타 사이트 금지.
- 먼저 `C:/Users/CMEDIA/Downloads/`의 기존 YTAL 보관본에서 고른다. 파일명·메모에 `YTAL` 표기.
- **업로드 전 보관함에서 저작자 표시 필요 여부를 재확인**한다. 곡마다 조건이 다르고 파일만 봐서는 알 수 없다.

### 내레이션이 있는 영상의 더킹 값
`0819` 현장음용 값(베드 0.22 / ratio 7)을 내레이션에 그대로 쓰면 **사실상 무음**이 된다(실제로 물린 적 있음).
→ 베드 **0.42**, `sidechaincompress` ratio **4** / threshold **0.06**.

### ASS 자막 겹침
앞 이벤트와 **수십 ms만 겹쳐도** libass 충돌회피가 줄을 위로 밀어 순서가 뒤집힌 채 끝까지 간다. 에러가 없다.
→ 여러 줄은 MarginV에 맡기지 말고 **`\an1\pos(x,y)`로 고정**(`\pos`가 있으면 충돌회피가 꺼진다).
