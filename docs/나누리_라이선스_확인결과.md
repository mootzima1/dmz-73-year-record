# KTV 나누리 라이선스 확인 결과 (2026-09-19, 로그인 세션)

## 결론 — 조립 착수 불가. 소재 경로를 바꿔야 한다.

e영상역사관에서 받아둔 대한뉴스 21편은 **나누리에서 정식 소재로 승격할 경로가 확인되지 않았다.**
필요한 항목들이 전부 **마스터본 = 공공누리 제4유형**이고, 4유형은 상업 이용과 변경(편집)이 **둘 다 금지**라
수익 채널인 조선영상실록에 쓸 수 없다.

## 추가 확인 (같은 세션, UI 자동화 우회)

- **클립본 전용 목록 URL**: `/shot/selectOrignalShotList.do` — 메뉴 링크에서 확보.
  철자가 `Origanl`(상세) / `Orignal`(목록)로 **서로 다르고 둘 다 오타**라 추측으로는 못 찾는다.
- **페이지네이션은 GET으로 동작**: `?pageIndex=N` (10건/페이지, 총 14,565건 = 약 1,457페이지).
  검색창·필터 체크박스는 자동화로 안 먹지만 이 경로로는 목록 전체를 읽을 수 있다.
- 등록일 기준 정렬 실측: p3=2026-09-17 / p25=2026-09-11 / p47=2026-09-03 / p55=2026-08-31.
- **클립본 구성**: 대부분 KTV 자체 취재(스케치·녹취·중계·즉시개방용). 옛 대한뉴스도 **계속 추가되는 중** —
  p25에서 `19940816 진해군항제_대한뉴스KC 제2004호`가 **2026-09-11 등록**으로 확인됐다.
  즉 1986년분이 지금은 없어도 나중에 들어올 수 있고, 반대로 지금 없는 건 확정이다.

### 사이트 자동화 제약 (기록)
검색 결과 카드 클릭, 영상유형 체크박스, 목록 내 검색창 제출이 **전부 자동화로 동작하지 않는다**
(ref 클릭·좌표 클릭·form_input+Enter·돋보기 버튼 클릭 모두 시도). 스크린샷은 렌더러가 반복 정지.
`javascript_tool`은 쿠키/쿼리 보안으로 차단. **동작하는 것은 `navigate`(GET)와 읽기 도구뿐**이므로,
나누리 작업은 GET으로 도달 가능한 경로만 쓰는 편이 빠르다.
