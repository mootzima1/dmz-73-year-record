# 「대추」 낭독 영상 — 로컬 작업 인계 (2026-10-18)

클라우드 세션에서 로컬 노트북(VS Code)으로 작업을 옮긴다.
작업 폴더: `sourvideo/1018 대추/`

## 목표 (사용자 요청 원문 요약)
- 「대추」 잔잔한 낭독 에세이, 1920x1080 30fps → `output.mp4`
- whisper 전사 + script.txt 대조 → `subtitles.srt` (자막 글은 원문 기준)
- 컷 5~8초, 사진은 Ken Burns 줌인, 컷 사이 1초 크로스 디졸브, 따뜻하고 채도 약간 낮게
- 내레이션 100%, BGM 약 20%, BGM 3초 페이드인/5초 페이드아웃, 내레이션 중 덕킹
- 자막: 나눔명조, 흰색, 약한 그림자, 하단 중앙, 최대 2줄, 문장 끝나면 부드럽게 사라짐
- 마지막 문장 "올 가을 대추는 유난히 붉고 오래도록 마음에 남는다." 화면 중앙 크게, 2초 유지 후 3초 페이드아웃
- 맨 앞 3초 타이틀 「대추」 (검은 배경, 흰 글씨 페이드인)
- 원본은 수정 금지, 작업 파일은 `work/`
- 얼굴이 크게 나오는 클립은 보고. 어려운 부분은 임의로 바꾸지 말고 먼저 물어볼 것.

## 이미 만들어 둔 것 (이 저장소 `tools/essay_film/`)
- `make_daechu.py` — 위 요구사항 전체 파이프라인. 합성 테스트 소스로 끝까지 렌더 확인(1920x1080).
  실제 Whisper 전사·실제 사진 얼굴 검출은 아직 미검증.
  - `--check-only`: 얼굴 검사·전사·컷 배치 계획만 출력
  - 소스 부족/과다, 원고-전사 불일치, 마지막 문장 불일치 시 멈추고 이유 출력(종료 코드 2)
  - 결정해 둔 것(바꿀 수 있음): 타이틀은 「」 포함 표시, 마지막 3초 화면도 함께 페이드아웃,
    부족하면 긴 영상만 나눠 쓰고 반복은 안 함, 16:9가 아닌 소스는 흐린 배경 위에 얹음
- `gen_images.py` — OpenAI 이미지 API용(키 필요). Higgsfield 쓸 거면 불필요.
- 그림 프롬프트·나누리 검색어: `docs/대추_소재_찾기.md`

## 로컬에서 할 일
1. 폴더 구성
   ```
   sourvideo/1018 대추/
   ├─ script.txt  narration.mp3  bgm.mp3
   ├─ clips/        (Higgsfield 그림 등, 01_ 02_ 번호 순)
   └─ make_daechu.py  (tools/essay_film/에서 복사)
   ```
2. 설치: ffmpeg, `pip install faster-whisper "opencv-python-headless==4.10.0.84"`, 나눔명조 폰트
   - Windows는 폰트 경로가 다르므로 `make_daechu.py`의 `fontsdir=/usr/share/fonts/truetype/nanum`
     (두 군데)을 나눔명조가 설치된 폴더(예: `C:/Windows/Fonts`)로 바꿔야 한다.
3. `python make_daechu.py "." --check-only` → 결과 확인 후 `python make_daechu.py "."`
